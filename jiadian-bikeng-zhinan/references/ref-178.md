# 什么样的灶具才是最好的？我买错了？12.16

▲民以食为天，对于我们国人来说却以爆炒为天。所以选购灶具就显得尤为重要。

▲大火力，这是国人选择灶具的第一要素，满足不同的烹炸炒。

▲火力大小，可以注意看灶具标识上的热负荷，热负荷越大火力越大，注意一般灶具4-5kw已经足够满足大部分人的家庭需求。同时注意，并不是热负荷越大，热量就越大，同时注意标识上的热效率，就是燃烧产生的热量被锅具吸收的多少，这个最低标准必须大于55%。

▲点火方式，一般只有两种，一种是过去的压电陶瓷点火，和现在普遍的电子脉冲点火。现在几乎大部分家用灶具都是后者，需要使用电池，不断更换。

▲灶具燃烧需要氧气，所以就存在进风模式，有上进风，下进风和全进风，也就是混合进风，现在市面上大部分都是混合进风，所以选购的时候最好关注一下。进风模式同样影响点火的快慢和燃烧的充足。一定要问清全进风的是否是全上进风，这样的进风模式是最安全，也不会出现回火现象，同时保证面板的安全性。

▲灶具火盖，也叫作分火器，也是灶具温度最高的部分，必须耐高温，耐腐蚀，同时还得兼顾美观。火盖的材质一般有铜质，铸铁，和钢制。好的灶具一般是铜质火盖，其他次之。所以选购的时候注意多留个心眼，多问一句。

▲熄火保护和儿童锁，也是购买灶具需要注意的。一旦有水溢出或者意外灭火，熄火保护会自动切断气源。儿童保护可以防止儿童意外打开，提高安全性。

▲灶具面板主流两种，一种是不锈钢像上图那样，一种是钢化玻璃。不锈钢面板要安全很多，不会出现爆裂的可能，但是不锈钢灶具在擦拭打理方面，表面会有各种划痕，而且从颜值来说，输于钢化玻璃

▲钢化玻璃面板颜值颇高，这也是目前市场上灶具的主流做法，好打理，好清洁，也不会有划痕，但是不耐撞击。不锈钢面板即使有硬东西砸到不会有任何问题，钢化玻璃就不行，一旦砸到会裂缝。最大的隐患是一旦碰到不合格的面板，在长期高温下，温度不均衡会产生爆炸的危险，这个基本新闻报道中常有的事情。所以选购灶具，千万不要图便宜，因为诸多新闻报道中爆炸的灶具，几百元一个，而且名字稀奇古怪，搞不好都是图便宜的山寨货。

▲安装方式一般都是内嵌式安装，当然你要放到台面上都是可以的，一般灶具都有两种安装方式。内嵌式注意在安装橱柜之前得看好灶具。如果厨房过小，需要细节设计，必须在设计橱柜的时候看好灶具，以便按照尺寸做到合理利用空间。

灶具的安装需要专业人士上门服务，一般商家都会提前安排，需要注意的是：灶具和燃气热水器的协调，一般家里都需要接燃气管（防爆管），这里就需要注意，燃气热水器和灶具都需要接，自己不需要购买，这两个商家都有提供，需要在预约安装的时候告知，人家会带上防爆管，最后用多少米付多少钱就行。让燃气热水器给你提供还是让灶具给你提供，你得考虑好，如果两者是一个商家，那再好不过。

切记不要图便宜，你自己买防爆管，一般发生管路裂缝等问题，售后就很麻烦。而且你自己买管子，说实话，图个便宜，人家再收个安装费用，最终是差不多的，但是结果是安装工不高兴，因为你没有用他提供的防爆管，当然不高兴。该赚的就让人家赚，你省事人家也省事。
