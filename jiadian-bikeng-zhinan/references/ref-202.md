# 冰箱和洗衣机放一块，怎么做更好看？4.7

关于冰箱和洗衣机放置的文章很多，可以后台回复“洗衣机”在电器版块里头查看相关专题，今天看一下如果洗衣机和冰箱在一个地方，怎么做更完美。

▲公寓式户型，进门的过道就是开放式厨房，对面就是卫生间空间，可以把冰箱靠近地柜放置，同时洗衣机可以镶嵌橱柜地柜，视觉和功能都可以达到。
▲同样开放式厨房，在最边上镶嵌冰箱，同时地柜镶嵌洗衣机和冰箱紧挨，视觉更完整整洁
▲同样公寓房，过道厨房空间，没有地方放置冰箱，可以把洗衣机和小的冰箱都镶嵌在地柜下方，满足基本的功能使用和视觉的完整统一
▲公寓房没有地方做厨房，只能做一个类似西厨的地方，同样可以采用洗衣机镶嵌地柜，角落放一个小的洗衣机，合理利用空间，视觉更美观，功能也能实现
▲厨房外面的西厨空间，统一收纳柜布局，满足门口冰箱镶嵌，同时地柜镶嵌洗衣机和烘干机，实现功能的最大化，而且视觉更美观
▲公寓小户型，厨房门口定制收纳柜以及吧台兼顾餐桌，镶嵌冰箱和洗衣机，视觉更美观，实现功能最大化

▲小户型，厨房做了户型的移门处理，同时把冰箱和洗衣机镶嵌进橱柜，视觉更美观，同时移门保证油烟的隔离

▲利用厨房门口做镶嵌的收纳柜，同时可以满足冰箱和洗衣机的镶嵌，保证视觉的完美整洁
▲厨房门口位置可以兼顾放冰箱以及洗衣机和烘干机的镶嵌，满足功能的同时保证视觉美观
▲利用厨房凹陷区刚好布局冰箱和洗衣机，同时洗衣机上方简单隔板，同样可以满足一些小的收纳功能
▲半开放式厨房，可以满足门口餐桌的位置，同时冰箱最边上镶嵌，洗衣机地柜镶嵌，视觉更简单美观
▲利用厨房门口做高柜收纳，同时满足冰箱和洗衣机的镶嵌，视觉美观同时更实用
▲小户型，开放式餐厨一体，高柜镶嵌冰箱和电器，地柜镶嵌洗衣机，小空间合理利用空间，同时视觉还得保证美观

▲根据空间可以借用电视墙的收纳柜，把洗衣机和冰箱做镶嵌处理，关上门以后视觉更美观，对于小户型非常实用的布局
