# 洗衣机不放阳台，还有6处可放6.9

第一、洗衣机放厨房

▲如果家里有西厨空间，满足洗烘机的布局再好不过，而且空间大可以并排布局，台面空间也不会浪费。
▲如果中厨有高柜的话，洗烘机也可以完全满足镶嵌的做法，而且整体也不会乱，其余高柜还能延伸厨房的收纳▲肯定有人会说，没有见过把洗衣机放厨房的，这个就看自己家的实力了，你家如果有独立洗衣间的话，谁也不会放厨房的。第二、放卫生间干区
▲如果家里卫生间是干湿分离，洗衣机放干区最合适不过，而且用水也方便▲如果洗烘机都有的话，干区叠放也不是问题，这样洗漱区照样可以满足，同时解决了生活刚需第三、放卫生间湿区
▲万不得已不建议洗烘机放到湿区空间，如果没有干湿分离，实在没有办法放湿区的话，淋浴区最好用隔断遮挡一下▲万不得已放湿区，淋浴区一定要做淋浴房，这样最大限度保证洗烘机的使用寿命第四、洗衣机放客厅
▲如图实在没有地方，也没有办法放进卫生间，可以借用卫生间隔壁，利用客厅区域镶嵌布局，这样满足了功能，同时也避免放卫生间影响使用寿命▲实在没有地方，电视墙后面就是卫生间，刚好利用空间满足洗烘机的镶嵌，如果嫌视觉有点乱，可以做个柜门遮挡一下也是可以的第五、独立洗衣间
▲独立洗衣间当然最好不过了，这个是最完美的做法了，满足了收纳，同时能保证空间更完美利用▲独立洗衣间的话，哪怕很小，也是非常完美的布局了第六、衣帽间放洗衣机▲衣帽间放洗烘机其实也是最方便的做法，洗干净烘干净的衣服刚好满足随手收纳▲衣帽间满足洗烘机的放置，实现家里完美的家务间以及衣服的收纳，使用更方便实用
