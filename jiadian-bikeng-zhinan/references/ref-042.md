# 客厅看电视，不是看墙4.1

电视墙系列已经够多了，完全可以满足装修的任何需求了，后台回复“电视墙”可以看看专题。

今天谈一下，现在装修都有什么样的电视墙，自己装修心里有个谱，不要花了钱，最后倒退到80年代。

什么都没有，就是电视

▲客厅放电视，肯定就是看电视，不是看墙。做花里胡哨的背景，是80年代的标配。因为装修没有替自己着想，而是想到以后来个朋友可以从电视墙看到自己的家很有钱的样子。

其实你想多了，有钱人从来都是很低调的，而不是做一个上万块的没用的电视墙，让别人来羡慕的，其实别人心里早都笑死了，因为实在没有品位可言，充其量就是一个土豪级别的暴发户而已。

▲你甚至都可以不要电视柜，直接把电源和信号盒子放到电视后面隐藏起来

功能性电视墙只为收纳

▲要不什么都不做，要不就实惠一点，做成颜值很高的收纳。最起码能满足家里的储物需求。同时还能兼顾客厅的装饰，这个不是一举两得的事情？对比一下，那些土豪级别的电视墙，上图是不是更有品味和功能？

▲你也可以做隐形收纳柜，直接内嵌电视，连电视柜也省了。看上去更整洁大气。

书柜电视墙

▲如果你有看书需求，文化人更不能做花里胡哨的电视墙。直接牺牲电视的娱乐性，做成满墙书柜，既满足藏书需求，又有了文化品位，这不是更十全十美的事情。

▲如果书柜和电视都想要，把书柜做低，上头投影或者电视都是可以满足的

太单调简单线条也行

▲实在觉得单调，用石膏线或者PU线，又或者钛金条勾勒个简单造型也行。同样不累赘，同样有品位，而且造价非常低。

连电视都不要

▲你也可以连电视都不需要，直接隐藏投影，平时偶尔可以娱乐一下，这样空间更开阔简洁

电视投影都不要

▲投影和电视都不要，客厅就是休闲和会客用，灵活的家具搭配，能让空间更温馨舒适
