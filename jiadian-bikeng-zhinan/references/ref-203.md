# 要不要电视不要纠结，看人家的装修效果3.6

现在好多年轻人把不要电视当做是潮流，这里有一个误区，功能性的东西取决于是否刚需，不要当做潮流，一定要根据自己的需求去决定《装修不要电视，难道是为了不让孩子看？》，今天看看这些不要电视的家庭怎么装修，然后你再决定是否需要。

▲现代日式风极简，经典的白色与木色搭配，干净温馨；客餐厅横厅布局，电视墙不做任何造型，简单的收纳柜布局，装饰兼顾收纳；电视墙斗柜上头摆放便携式投影，如果想要偶尔娱乐的时候，直接投到电视墙白墙即可，平时让视觉空间更干净清爽

▲刚需小户型，为了拓展空间做了开放厨房，满足基本的就餐区域；压根没有地方布局电视功能，同时对于电视也没有刚需，所以干脆不要电视，让空间看起来更简单宽敞

▲如果你是爱书之人，或者和职业有关需要有大量藏书需求，同时平时也没有看电视的习惯，那电视墙完全可以打造成家里的书墙，用来满足自己的刚需

▲经典的横厅黑白灰，没有电视的需求，把电视墙直接打造成一整面墙的收纳柜，用来满足家里的杂物收纳，空间也能极简清爽

▲没有看电视的刚需，但是有钢琴的需求，完全可以把电视墙打造成收纳，同时镶嵌钢琴位置，完美实现公共区域的活动以及娱乐功能
▲如果家里有大量藏书需求以及展示需求，电视墙可以整体布局成书柜形式，不占地，而且完美实现刚需
▲不要电视，电视墙整体做了收纳柜以及展示架，但是偶尔有娱乐需求，可以利用收纳柜上方吊顶隐藏投影幕布，可以满足偶尔全家的娱乐需求
▲你如果崇尚的是极简艺术之家，当然可以舍弃电视，电视墙采用悬空艺术柜布局，不仅满足一定的收纳，而且让空间达到极简艺术美
▲把一间房子做成了玻璃房，不要电视，上方隐藏投影，满足偶尔的娱乐，整个客厅更加通透开阔
▲不要电视墙面又不要柜子，不能电视墙空着，可以放个电视柜，一副挂画斜靠搞定，看起来空间也能高级一点
▲电视墙做整面墙的收纳柜，只要设计好了，非常高级美观，做个投影满足偶尔的娱乐就行
▲如果是小户型刚需，完全可以极简布局，一个沙发一个单椅，休闲布局，同时旁边非常轻巧的书柜即可，家有小孩也能腾出更多地方活动，同时孩子拿取书籍也非常方便
▲如果客厅跨度大的话，不要电视，可以做成开放式书房形式，满足平时的聚会，同时在家办公也方便多了，有孩子可以做作业，做手工也是非常方便
