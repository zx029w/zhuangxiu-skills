# 洗衣机做地台？过时or新潮？1.23

▲上图就是所谓的洗衣机地台，阳台一角，用红砖砌个高台放置洗衣机，角落是一个小的拖把池，洗衣服脱水的时候，不浪费水，把洗衣机废水放入拖把池，供洗拖把使用。

以上就是洗衣机地台。这是在某个工地发现一家装修正在做的，而且还做了弧形处理。

业主的理由是：1.利用洗衣机废水洗拖把 2.洗衣机高了，洗衣服可以不再弯腰

好吧，看着业主年龄大的份上，没有敢说，这做的是什么呀。

第一洗衣机洗完的废水多脏？然后洗拖把，然后用这个拖把再去拖客厅的地？家里的味道还能闻吗？

第二，全自动滚动洗衣机放到这个台上？你不弯腰咋开门？

第三，如果你用老式的上开门洗衣机，好吧，那种洗衣机脱水的时候震动非常大，不怕掉到地上。

分析了半天实在找不到这种又花钱，又没有颜值的做法一点优点。

不过在网上搜了一下，这样做的不在少数，看看这些大同小异的洗衣机地台：

▲还是一样的做法，砌个地台放置洗衣机，然后旁边单独做了拖把池，不过上图的做法拖把池稍高，其实都是一样的，为了把洗衣机的废水再利用

有的人说了，如果洗衣机放置卫生间，害怕有水，可以做个地台，像这种：

▲像上图这种洗衣机底座，而且带个滑轮的，不知道这种底座，是为了平时随意移动吗？可以搬来搬去而发明？如果没有地方固定放置洗衣机，平时使用的时候需要移动，这个滑轮真的可以。如果是洗衣机在卫生间的话，害怕水，放个底座一点用都没有，潮湿的地方，即使你放个底座，洗衣机还是在潮湿环境，还是会减少寿命的。而且带滑轮底座，洗衣机脱水是会震动的，这个会导致洗衣机随意摆动，反而是鸡肋。可能大部分洗衣机放置卫生间加底座，并不是为了洗衣机寿命，而是为了好打扫卫生，天啊，不为洗衣机寿命考虑，只为了面子干净。

▲你如果非常想用砖砌，阳台可以用这种方式，镶嵌洗衣机，旁边砖砌一个单独的拖把池，也不要废水利用了，那个水真的不能利用

▲卫生间干区放置洗衣机也可以用砖砌的方式制作，直接镶嵌就行

▲即使放厨房，也是直接镶嵌的

通过上面的各种举例，可以总结洗衣机放置哪都是不需要底座和地台的，如果你真的不嫌难看，自己喜欢做地台或者底座也行，那个把洗衣机脏水回收的做法还是免了吧，省钱真的不在那地方省，一天少抽一包烟都出来了，牺牲生活品质而节省，这个和人类文明背道而驰。
